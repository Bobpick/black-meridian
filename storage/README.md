# BLACK MERIDIAN storage

Use this directory for exported scenario drafts, order logs, scorecards, and exercise-control notes.

The browser dashboard cannot reliably save directly into this directory when opened as a local HTML file. Use an Export button, then move the downloaded file here.

Suggested filenames:

- `scenario-export-YYYY-MM-DD.json`
- `orders-YYYY-MM-DD.json`
- `scorecard-YYYY-MM-DD.json`
- `facilitator-notes-YYYY-MM-DD.md`
